# Кодекс прокачки — Warhammer 40 000: Rogue Trader

**[Открыть приложение →](https://k41n.github.io/wh40krt/)** · [English](README.en.md)

Офлайновое PWA для телефона: выбираешь персонажа, билд и уровень — приложение
говорит, что именно брать на этом уровне. Без респеков и без метаний по вики
посреди боя.

## Установка на телефон

1. Открыть **https://k41n.github.io/wh40krt/** в браузере телефона.
2. **iOS (Safari):** «Поделиться» → «На экран «Домой»».
   **Android (Chrome):** меню «⋮» → «Установить приложение».
3. После первой загрузки работает офлайн — данные лежат в кэше.

Приложение обновляется само: при запуске и при возврате к нему оно проверяет
новую версию, и если она есть — внизу появляется плашка **«Есть новая версия
кодекса → Обновить»**. Нажал — обновилось. Если проигнорировать, обновление
применится при следующем запуске.

## Как пользоваться

- **Главный экран** — 12 компаньонов, Вольный Торговец и «секретные» персонажи.
  Шестерёнка сверху — переключатели DLC: выключенное DLC прячет билды,
  которые без него не собрать.
- **Персонаж** → список готовых билдов (у Абеляра 8, у Хайнрикса 12,
  у ГГ — 64 варианта под разные архетипы и оружие).
- **Билд** → три вкладки:
  - **Уровень** — ползунок 1–55 и главное: «Уровень 28 — бери: …».
  - **План 1–55** — вся схема прокачки сразу, разбитая по ступеням.
  - **Снаряжение** — что надеть, по слотам.
- Тап по таланту или способности открывает описание.

## Модель прокачки в игре

Потолок — 55 уровней, три ступени архетипов:

| Уровни | Ступень | Что происходит |
|---|---|---|
| 1–15 | I | базовый архетип: воин, солдат, оперативник, офицер, танцор смерти *(Void Shadows)* |
| 16–35 | II | продвинутый: ассасин, авангард, архмилитант, мастер-тактик, великий стратег, охотник за головами, палач *(Void Shadows)*, надзиратель *(Lex Imperialis)* |
| 36–55 | III | гранд-магистр — добирает таланты и способности из двух предыдущих ступеней |

Ступень II доступна не из любой ступени I — билды в приложении уже учитывают
допустимые связки.

Билды рассчитаны на прохождение 1–55 **без респека**: ранние уровни заточены под
конкретных боссов (ур. 15 — Аврора, 18–21 — Кузнец-демон, 30 — Фабрикатор Дельфим,
40 — Иремерисс, 50 — Уралон и «Рассвет»).

## Русские названия

Названия архетипов, талантов, способностей, характеристик и навыков —
официальные, из локализации игры. Сопоставление сделано по UUID
(`enGB[uuid] → ruRU[uuid]`), покрытие 15 051 из 15 085 выборов (99.8 %).
Английское название остаётся рядом с русским — чтобы сверяться с вики.

Непереведённых мелочей осталось три десятка: это опечатки и сокращения
автора гайда (`MSSP`, `Combat Locust`, свободные ремарки вроде
«Lore Imperium (Chartist Pendant)») — они показываются как есть.
Описания талантов английские: они взяты из таблицы-гайда, а не из игровых строк.

Если нужно пересобрать перевод (например, после патча игры), скопируй из папки игры

```
<Steam>/steamapps/common/Warhammer 40,000 Rogue Trader/WH40KRT_Data/StreamingAssets/Localization/
    enGB.json
    ruRU.json
```

и запусти:

```
python3 tools/apply_ru.py enGB.json ruRU.json
```

## Что внутри

| файл | что это |
|---|---|
| `index.html` | всё приложение: разметка, стили, логика |
| `data.json` | 150 билдов на 17 персонажей + словарь на 793 таланта/способности |
| `sw.js` | service worker: офлайн, network-first для `index.html` и `data.json` |
| `manifest.webmanifest`, `icon*.png/svg` | PWA-обвязка |
| `tools/` | скрипты, которыми собран `data.json` |

## Локальный запуск

Статика, никакой сборки. Нужен любой HTTP-сервер (service worker не работает с `file://`):

```
python3 -m http.server 8765
# открыть http://<ip-компьютера>:8765/ на телефоне
```

## Пересборка `data.json`

```
cd tools
python3 build_data.py   # тянет разобранные CSV-выгрузки таблицы → data.json
python3 enrich.py       # классифицирует выборы и подтягивает описания
cd ..
python3 tools/apply_ru.py enGB.json ruRU.json   # подставляет русские названия
```

`build_data.py` ожидает рядом CSV-выгрузки вкладок таблицы
(`s_<gid>.csv`, скачиваются через `gviz/tq?tqx=out:csv&gid=<gid>`).

## Деплой

GitHub Pages раздаёт ветку `main` из корня репозитория. Перед `git push`
обнови поле `VERSION` в `sw.js` — по нему установленные приложения понимают,
что вышла новая версия.
