# Кодекс прокачки — Warhammer 40 000: Rogue Trader

**[Открыть приложение →](https://k41n.github.io/wh40krt/)** · [English](README.en.md)

Офлайновое PWA для телефона: выбираешь персонажа, билд и уровень — приложение
говорит, что именно брать на этом уровне. Без респеков и без метаний по вики
посреди боя.

## Установка на телефон

1. Открыть **https://k41n.github.io/wh40krt/** в браузере телефона.
2. **iOS (Safari):** «Поделиться» → «На экран «Домой»».
   **Android (Chrome):** меню «⋮» → «Установить приложение».
3. После первой загрузки работает офлайн — данные лежат в кэше.

Приложение обновляется само: при запуске и при возврате к нему оно проверяет
новую версию, и если она есть — внизу появляется плашка **«Есть новая версия
кодекса → Обновить»**. Нажал — обновилось. Если проигнорировать, обновление
применится при следующем запуске.

## Как пользоваться

- **Главный экран** — 12 компаньонов, Вольный Торговец и «секретные» персонажи.
  У тех, кого уже качаешь, прямо в строке написано, **какой билд выбран и что
  брать дальше** («Дальше — ур. 12: Меткий выстрел»); тап открывает сразу этот
  уровень.
  Шестерёнка сверху — переключатели DLC: выключенное DLC прячет билды,
  которые без него не собрать.
- **Персонаж** → сверху карточка **«Как выбрать»**: чем билды отличаются
  и с какого начать. Дальше список билдов, сгруппированный по архетипу
  II ступени; у каждого — метка роли («универсальный урон», «танк, держит
  удар», «лишние ходы отряду»…), а у рекомендованного — «советую начать
  с него». У Абеляра 8 билдов, у Хейнрикса 12, у ГГ — 64.
- **Билд** → три вкладки:
  - **Уровень** — ползунок 1–55 и главное: «Уровень 28 — бери: …».
  - **План 1–55** — вся схема прокачки сразу, разбитая по ступеням.
  - **Снаряжение** — что надеть, по слотам.
- На вкладке «Уровень» кнопка **«Взял — дальше»** отмечает уровень пройденным
  и перематывает к следующему выбору. Прогресс хранится в браузере (localStorage),
  отдельно для каждого персонажа; сбросить можно там же.
- Тап по таланту или способности открывает описание — русское, с английским
  оригиналом мелким шрифтом под ним.
- Билды, которых коснулись патчи после выхода гайда, помечены **«правка патчем
  1.6.1»**, а внутри билда есть карточка «Что изменилось после гайда».
  Полный список — в шестерёнке, раздел «Актуальность».

## Модель прокачки в игре

Потолок — 55 уровней, три ступени архетипов:

| Уровни | Ступень | Что происходит |
|---|---|---|
| 1–15 | I | базовый архетип: воин, солдат, оперативник, офицер, танцор смерти *(Void Shadows)* |
| 16–35 | II | продвинутый: ассасин, авангард, архмилитант, мастер-тактик, великий стратег, охотник за головами, палач *(Void Shadows)*, надзиратель *(Lex Imperialis)* |
| 36–55 | III | гранд-магистр — добирает таланты и способности из двух предыдущих ступеней |

Ступень II доступна не из любой ступени I — билды в приложении уже учитывают
допустимые связки.

Билды рассчитаны на прохождение 1–55 **без респека**: ранние уровни заточены под
конкретных боссов (ур. 15 — Аврора, 18–21 — Кузнец-демон, 30 — Фабрикатор Дельфим,
40 — Иремерисс, 50 — Уралон и «Рассвет»).

## Русские названия

Всё, что видно в приложении, — по-русски: архетипы, таланты, способности,
характеристики, навыки, предметы, слоты, названия и описания билдов.
Английский оригинал остаётся рядом мелким шрифтом — чтобы сверяться с вики.

Источник — сама игра: сопоставление по UUID (`enGB[uuid] → ruRU[uuid]`).

| слой | покрытие | откуда |
|---|---|---|
| названия выборов | 15 051 / 15 085 (99.8 %) | локализация игры |
| описания талантов | 701 / 793 из игры + 92 вручную = **793** | локализация игры + `tools/ru_manual.json` |
| предметы снаряжения | 3 028 / 3 216 из игры + остальное вручную | то же |
| названия билдов, «замысел», слоты, ремарки | 150 названий, 138 описаний | вручную (это текст автора гайда, в игре его нет) |

Непереведёнными остались три десятка мелочей: опечатки и сокращения автора
гайда (`MSSP`, `Combat Locust`, ремарки вроде «Lore Imperium (Chartist
Pendant)») — они показываются как есть.

Из игровых описаний вычищена внутренняя разметка (`{g|…}`, `{br}`),
а вычисляемые числа (`{uip|…}`) заменены на «…» — их игра подставляет
по твоим характеристикам.

Если нужно пересобрать перевод (например, после патча игры), скопируй из папки игры

```
<Steam>/steamapps/common/Warhammer 40,000 Rogue Trader/WH40KRT_Data/StreamingAssets/Localization/
    enGB.json
    ruRU.json
```

и запусти:

```
python3 tools/apply_ru.py enGB.json ruRU.json        # названия
python3 tools/apply_ru_desc.py enGB.json ruRU.json   # описания и предметы
python3 tools/apply_ru_manual.py                     # то, чего в игре нет
```

## Что внутри

| файл | что это |
|---|---|
| `index.html` | всё приложение: разметка, стили, логика |
| `data.json` | 150 билдов на 17 персонажей + словарь на 793 таланта/способности |
| `sw.js` | service worker: офлайн, network-first для `index.html` и `data.json` |
| `manifest.webmanifest`, `icon*.png/svg` | PWA-обвязка |
| `tools/patch_notes.py` | слой актуальности: что изменилось в игре после того, как гайд собрали |
| `tools/ru_manual.json` | ручной перевод: названия и описания билдов, слоты, редкие предметы, советы «как выбрать» |
| `tools/` | скрипты, которыми собран `data.json` |

## Локальный запуск

Статика, никакой сборки. Нужен любой HTTP-сервер (service worker не работает с `file://`):

```
python3 -m http.server 8765
# открыть http://<ip-компьютера>:8765/ на телефоне
```

## Пересборка `data.json`

```
cd tools
python3 build_data.py   # тянет разобранные CSV-выгрузки таблицы → data.json
python3 enrich.py       # классифицирует выборы и подтягивает описания
cd ..
python3 tools/apply_ru.py enGB.json ruRU.json        # русские названия из игры
python3 tools/apply_ru_desc.py enGB.json ruRU.json   # русские описания и предметы из игры
python3 tools/apply_ru_manual.py                     # ручной слой: билды, слоты, «как выбрать»
python3 tools/patch_notes.py                         # пометки о патчах после гайда
```

Порядок важен: каждый следующий скрипт дополняет то, что не нашёл предыдущий.

`build_data.py` ожидает рядом CSV-выгрузки вкладок таблицы
(`s_<gid>.csv`, скачиваются через `gviz/tq?tqx=out:csv&gid=<gid>`).

## Актуальность

| что | версия |
|---|---|
| данные билдов | таблица Revan619, «Build cover up to patch 1.6» |
| игра, на которой сверялось | 1.6.1.514 (хотфикс от 20 июля 2026) |
| последняя сверка | 29 августа 2026 |

Все 19 листов таблицы на 29 августа 2026 побайтово совпадают с теми, из которых
собран `data.json`, — автор гайда с тех пор ничего не менял.

Единственный балансный патч после того, как гайд собрали, — **1.6.1.493**
от 30 июня 2026 (дальше только исправления багов). Из него в приложение
занесены: ослабление связок Эоганна, потолок бонуса у «Раненого зверя» и
«Привечая конец», «Осевая фортификация» Паскаля только по шоку, усиленная
«Хватка огрина». Баг с посохами псайкера не исправлен — билды гайда на нём
по-прежнему работают. 11 билдов помечены в списке.

Чтобы пересверить: `tools/patch_notes.py` — там даты, версии и тексты
пометок; после правки запустить его последним в конвейере.

## Деплой

GitHub Pages раздаёт ветку `main` из корня репозитория. Перед `git push`
обнови поле `VERSION` в `sw.js` — по нему установленные приложения понимают,
что вышла новая версия.
